## 附录

### 附录 A：两部主要著作概要

**《逻辑哲学论》（Tractatus Logico-Philosophicus, 1921）**

以编号命题形式写成，只有约75页，却试图"从根本上终结哲学问题"。七个主命题：

1. 世界是一切发生的事情的总和。（Die Welt ist alles, was der Fall ist.）
2. 发生的事情——事实——是事态的存在。
3. 事实的逻辑图像是思想。
4. 思想是有意义的命题。
5. 命题是基本命题的真值函数。
6. 真值函数的一般形式是 [p̄, ξ̄, N(ξ̄)]。
7. 对于不可言说之物，我们必须保持沉默。（Wovon man nicht sprechen kann, darueber muss man schweigen.）

**《哲学研究》（Philosophische Untersuchungen, 1953 遗作）**

以对话式的"评论"（Bemerkungen）形式写成，分为两部分。核心主题：

- §1-64：对奥古斯丁语言图像的批评；语言游戏概念的引入
- §65-88：家族相似性；概念的模糊边界
- §89-133：哲学的本质——描述而非解释；治疗性目标
- §134-242：规则遵循问题
- §243-315：私人语言论证；疼痛行为主义的拒绝
- §316-693：心理学概念的语法分析

### 附录 B：维特根斯坦的生平

| 时间 | 事件 |
|------|------|
| 1889 | 出生于维也纳最富有的工业家族之一 |
| 1908-11 | 在曼彻斯特学习航空工程 |
| 1911-13 | 转至剑桥跟随罗素学习逻辑 |
| 1914-18 | 参加一战，在战壕中完成《逻辑哲学论》初稿 |
| 1921 | 《逻辑哲学论》出版——他认为哲学问题已经"终结" |
| 1920-26 | 放弃哲学，在奥地利乡村当小学教师 |
| 1926-28 | 为姐姐设计建造住宅（严格的现代主义风格） |
| 1929 | 回到剑桥，重新开始哲学工作 |
| 1930s-40s | 剑桥教学与写作——思想逐渐转向后期立场 |
| 1947 | 辞去剑桥教职 |
| 1949 | 完成《哲学研究》终稿 |
| 1951 | 4月29日在剑桥去世，最后的话："告诉他们，我度过了美好的一生" |
| 1953 | 《哲学研究》作为遗作出版 |
